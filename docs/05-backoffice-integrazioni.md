# 05 — Backoffice operatore e integrazioni

## Area operatore (backoffice)

- Gestione pratiche e stati
- Assegnazione carichi di lavoro
- Comunicazione con gli utenti
- Validazione documenti
- Reportistica e statistiche
- Gestione calendario appuntamenti

## Integrazioni previste

| Ente / Sistema | Utilizzo |
|---|---|
| **SPID / CIE** | Identità digitale e accesso |
| **Agenzia delle Entrate** | Servizi fiscali |
| **INPS** | Previdenziale e assistenziale |
| **INAIL** | Infortuni sul lavoro |
| **Comuni** (es. IMU, anagrafe) | Servizi locali |
| Altri enti pubblici (Regioni, Ministeri) | Estensioni future |

## Note tecniche sulle integrazioni

- Valutare per ciascun ente: disponibilità di API, convenzioni, tempi di accreditamento
- Dove le API non sono disponibili: flusso assistito con generazione modulistica precompilata
- Priorità MVP: SPID/CIE + INPS + Agenzia delle Entrate
