# 07 — Tecnica, UX, monetizzazione e roadmap

## Architettura tecnica (proposta)

- **Sviluppo nativo / cross-platform** (Android, iOS) — da valutare: Flutter o React Native
- **Architettura scalabile** (Cloud)
- **API REST** / integrazioni con enti esterni
- Aggiornamenti automatici
- Gestione versioni
- Monitoring e logging

## UX Mobile

- Interfaccia semplice e intuitiva
- **Accessibilità (WCAG)**
- Design coerente e moderno
- **Multilingua**
- Notifiche push
- Esperienza personalizzata

## Monetizzazione (ipotesi)

- Servizi gratuiti tradizionali
- Servizi a pagamento (es. consulenze, pratiche non coperte)
- Abbonamenti / pacchetti
- Pagamenti digitali (carta, PayPal, Satispay)
- Codici sconto / convenzioni

## Operatività

- Assistenza utenti (ticketing)
- Formazione operatori
- Manuali e guide in app
- Supporto multicanale (chat, email, telefono)
- Monitoraggio SLA
- Piano di comunicazione e lancio

## Roadmap indicativa

| Fase | Contenuto |
|---|---|
| **0. Concept** | Documentazione funzionale, studio fattibilità, analisi normativa |
| **1. MVP** | Registrazione + SPID/CIE, 2-3 servizi CAF e 2-3 Patronato, upload documenti, stato pratica, notifiche |
| **2. Backoffice** | Area operatore completa, calendario appuntamenti, reportistica |
| **3. Smart** | Scanner documenti, compilazione assistita AI, simulatore ISEE, chat assistenza |
| **4. Integrazioni** | INPS, Agenzia delle Entrate, Comuni, INAIL |
| **5. Scale** | Multilingua completo, pagamenti, convenzioni, lancio territoriale |
