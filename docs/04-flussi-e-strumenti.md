# 04 — Flussi pratiche e strumenti smart

## Come funziona una pratica

```
Registrazione → Scelta servizio → Compilazione dati → Caricamento documenti
      → Invio pratica → Verifica operatore → Eventuale integrazione → Completamento
```

Ogni pratica resta **tracciata e consultabile** nello storico.

## Flussi pratiche (funzionalità)

- Nuova pratica guidata
- Caricamento documenti (foto/PDF)
- Stato pratica in tempo reale
- Comunicazioni e notifiche
- Scadenze e promemoria
- Pagamento (se previsto)
- Archiviazione e storico pratiche

## Strumenti smart

- **Scanner documenti** integrato
- **Compilazione assistita** con AI / suggerimenti
- **Calcolo ISEE / simulazioni**
- **Checklist documenti personalizzate**
- Prenotazione appuntamenti
- **Chat assistenza / virtual assistant**
- Notifiche intelligenti
